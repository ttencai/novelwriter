# 网文正文润色

## Purpose

把已有小说正文润得更顺、更清楚、更有阅读感。重点是保留原剧情，优化表达、节奏、动作承接和人物口吻。

## Scope

适合：
- 句子不顺、段落松散、读起来卡顿
- 动作、对话、心理之间衔接生硬
- 情绪不够具体，场面缺少临场感
- 人物说话不够贴合身份
- 章节节奏偏平，需要增强冲突和阅读动力

不处理：
- AI检测、反检测、平台风控
- 承诺降低检测率
- 为了“去AI味”刻意打乱文本
- 新增大段剧情或改写人物关系

## Instructions

### 润色原则

1. 保留原剧情、人物关系、事件顺序和关键信息。
2. 只改表达，不擅自新增设定、伏笔、人物或结局。
3. 优先让文字自然、清楚、有网文节奏。
4. 不把小说改成说明文，不把口语改成书面腔。
5. 不追求华丽辞藻，优先让读者读得顺。

### 润色重点

#### 句子
- 拆开过长、过绕的句子。
- 合并重复表达。
- 去掉多余解释和空泛判断。
- 让句长有变化，但不要故意破碎。

#### 动作
- 动作要承接清楚，谁做了什么要明确。
- 避免角色只“看着”“沉默”“愣住”反复出现。
- 情绪尽量落到身体反应、动作和选择上。

#### 对话
- 对话要符合人物身份和当下立场。
- 少写解释设定的长对话。
- 每段对话最好推动冲突、关系或信息变化。
- 保留角色口癖，不把所有人改成同一种声音。

#### 场景
- 细节服务剧情，不堆环境描写。
- 战斗、争吵、打脸场景用短句提速。
- 情感场景允许停顿，但不要连续抒情。
- 日常场景要有动作和物件支撑，不要只写心理。

### 输出方式

默认只输出润色后的正文。
只有用户要求说明时，才附简短修改说明。

## Execution Protocol

1. 判断文本主要问题：不顺、重复、拖沓、对话假、动作弱、情绪空。
2. 保留事实和剧情骨架。
3. 按句子、动作、对话、场景顺序润色。
4. 最后通读一遍，确认语气一致、没有说明文腔、没有新增剧情。
