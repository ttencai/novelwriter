# 分层去AI味策略

## 总原则

去AI味不是制造错别字，也不是把文字改乱。目标是保留剧情骨架，把模型习惯改成作者选择。

## 词汇层

优先处理高频AI词和空泛词：

| 少用 | 改法 |
|---|---|
| 至关重要 | 直接写为什么重要 |
| 深刻体现 | 删除，换成具体动作或结果 |
| 显著提升 | 写提升在哪里 |
| 赋能、闭环、底层逻辑 | 换成朴素说法 |
| 然而、此外、因此密集出现 | 改成自然转折或直接删掉 |

## 句式层

重点打破这些结构：

- 不仅是X，更是Y
- 从X到Y
- 这不仅意味着……也说明……
- 在某种意义上
- 这一刻，她终于明白

处理方式：

1. 删掉前半句铺垫。
2. 只保留真正发生的事。
3. 把抽象判断改成角色动作或一句短对白。

## 段落层

AI段落常见问题是太完整、太会总结。

处理顺序：

1. 删除开头热身句。
2. 删除结尾升华句。
3. 把中间解释改成动作、对话、结果。
4. 让段落长短有差异。

## 对话层

AI对话常像在讲设定。

改法：

- 一句话只说一个意图。
- 允许角色打断、回避、讽刺、装傻。
- 用身份和利益决定说法。
- 能用动作表现的信息，不塞进台词里。

## 情绪层

少写情绪标签，多写身体反应和选择。

| AI写法 | 更自然的写法 |
|---|---|
| 她内心五味杂陈 | 她把那句话听完，半天没接话 |
| 他感到无比愤怒 | 他抬手砸了杯子 |
| 空气仿佛凝固 | 屋里没人再说话 |

## 结尾层

去掉“总结意义”，留下“下一步动作”。

可用结尾：

- 新人物出现
- 门外传来声音
- 证据被拿出来
- 反派发现不对
- 主角做出选择
- 冲突升级
